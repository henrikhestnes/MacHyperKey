# MacHyperKey 1.0.2

- Fixed ⌃⌥⌘ staying held after releasing the hyper key, which left apps such as Slack showing their modifier hints until the next click.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew upgrade --cask henrikhestnes/tap/machyperkey
```

Or download `MacHyperKey.zip`, unzip it, and move **MacHyperKey.app** to **Applications**.

This build is signed with the same self-signed certificate as earlier releases, so the Accessibility permission carries over. It has not been notarized by Apple.
