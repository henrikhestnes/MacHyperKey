# MacHyperKey 1.0.0

Turns caps lock, or another key, into a hyper key (⌃⌥⌘).

- Choose the hyper key: caps lock, a left or right modifier, tab, `` ` ``, §, esc, or F13–F19.
- Remap caps lock separately when it is not the hyper key.
- Quick press the hyper key alone to type esc, toggle caps lock, or another key.
- Optionally include shift, and add the hyper modifiers to clicks, drags, mouse moves, and scrolling.
- Open on login, and run without a menu bar icon.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew install --cask henrikhestnes/tap/machyperkey
```

Or download `MacHyperKey.zip`, unzip it, and move **MacHyperKey.app** to **Applications**.

On first launch, enable MacHyperKey in **System Settings → Privacy & Security → Accessibility**.

This build is signed with a self-signed certificate and has not been notarized by Apple. macOS may block the downloaded app through Gatekeeper. The cask does not disable or bypass Gatekeeper.
