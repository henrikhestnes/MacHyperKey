# MacHyperKey 1.0.1

- Holding the hyper key on its own no longer sends ⌃⌥⌘ key presses. Apps that react to a bare modifier, such as Slack's numbered tab hints, no longer light up. The modifiers are pressed the first time hyper is used with a key, click or scroll, and released with hyper.

Requires macOS 14 or newer. The attached app supports Apple Silicon and Intel Macs.

## Install

```sh
brew upgrade --cask henrikhestnes/tap/machyperkey
```

Or download `MacHyperKey.zip`, unzip it, and move **MacHyperKey.app** to **Applications**.

This build is signed with the same self-signed certificate as 1.0.0, so the Accessibility permission carries over. It has not been notarized by Apple.
